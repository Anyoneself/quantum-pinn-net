# 文献阅读与 reference.md 合成

在完整起稿、文献补充或风格规范更新时使用。局部语言修改不必重启检索。

## 两类文献，各有用途

| 文献角色 | 选择依据 | 产出 |
| --- | --- | --- |
| 风格样本 | 与研究领域和论文类型相近、论证充分的中国核心期刊论文 | 提炼为规范性的 `reference.md` |
| 研究证据 | 直接支撑背景、方法来源、已有成果、基线选择和研究差异的论文 | 不少于30篇已阅读论文及正文引用 |

两类可以重叠。用户指定范文时优先使用；数量未指定时先选少量有代表性的样本，必要时补充，不为了风格分析批量下载。完整稿的30篇不要求全部来自中文核心期刊，应覆盖相关中国研究及国际原始成果。

## 检索、获取和核验

1. 从研究材料提取研究对象、核心方法、研究条件和待解决问题，组成中文与英文检索词。优先检索直接相关研究，再沿参考文献和后续研究补全方法谱系。
2. 通过期刊官网、出版商、学术数据库、机构仓储或合法开放全文阅读文章。遵守登录授权、访问限制、版权及网站抓取规则，不绕过付费墙、验证码或限流；不通过一次写作请求购买文献。
3. 对核心期刊身份记录实际采用的目录体系、版本或时间，以及可靠核验来源；不能把不同体系混称或仅凭宣传页认定。
4. 每条书目核对作者、题名、年份、期刊、卷期、页码或文章号、DOI。没有 DOI 的中文论文可凭可核验的期刊记录引用，不编造标识。
5. 合并预印本与正式版本等重复工作，通常引用正式发表版本。留意撤稿、更正和版本差异，不把失效成果当作普通支持性证据。
6. 用户限定下载数量或禁止联网时遵守限制；可阅读已有或在线全文，但不能偷换限制。材料不足时报告实际缺口，不声称满足了阅读量。

工具优先复用当前环境可用的学术检索、合法全文获取和 PDF 提取能力；这些能力不可用时用公开网页和本地文件，不把某个外部插件写成必备前提。

## 阅读深度与留痕

每篇计入30篇要求的论文，至少实际阅读与引用判断有关的问题定义、方法、实验设置、结果或结论段落及关键图表。涉及局限性、因果解释或机制主张时，继续阅读相应证据与讨论。搜索摘要、数据库简介或引用量不能代替成果阅读。

仅能获得摘要的文献标为“摘要可见”，不得计入已充分阅读的30篇。寻找合法全文或替换为同样相关的可读成果；如果无法补足，交付时明确不满足该要求。不能宣称“读过全文”却只有摘要访问记录。

在 `literature-notes.md` 或已有阅读记录中记录：

| 字段 | 内容 |
| --- | --- |
| 稳定 ID 与书目 | 去重后的唯一标识、完整书目信息 |
| 核验与阅读来源 | 可靠页面、DOI、合法全文链接或本地文件；访问日期 |
| 阅读范围 | 实际读到的章节、页码、图表，或明确的访问限制 |
| 研究结果 | 任务、关键方法、主要发现及成立条件 |
| 引用用途 | 本文准备引用的具体判断，不写泛泛“与本文相关” |
| 边界与差异 | 局限、可比性、与拟撰写研究的异同 |
| 状态 | 候选、已核验、已读相关全文、已引用，分别标记 |

数值须附原文位置和比较条件，不跨数据集或指标移用。阅读笔记用自己的概括，不复制长段原文或原论文图。区分作者报告的结论与自己的推断。

阅读作者公开稿而引用正式发表版本时，明确记录两者的版本对应关系，核对所引成果在对应版本中成立；未核实的差异不写成定论。记录“相关原文已读”不等于声称逐字读完全文及附录。保留可回溯的原文位置与合法来源；本地阅读材料的保存遵守用户下载范围和版权限制，不为留痕擅自批量下载。

按研究问题组织文献综述，而非逐篇排列摘要。每项引用对应相邻的具体判断；全文参考文献与正文编号双向对应。最终单独统计“列入条目数、去重论文数、充分阅读数、实际引用数”，不能以下载数量代替。

题录条数、文件存在或阅读记录字段齐全只能用于一致性检查，不能据此自动判定文献真实或已经理解成果。补充、替换或删除引用后，按目标期刊规则更新顺序和全文交叉引用，并检查阅读台账与最终文献表一致。

## 从范文提炼规范

先在阅读笔记中分析范文的可测特征：

- 摘要如何从问题转入方法、验证与定量结果。
- 引言怎样组织方法路线、比较前提与尚存问题。
- 方法说明如何平衡公式、图示、设计依据和实现细节。
- 验证如何安排对照、必要消融、不同条件、诊断与负面结果。
- 结果段落如何结合数值、图表、解释与应用条件。
- 正文、摘要、各节的篇幅，图表数及各图承担的证据任务。
- 句子和段落的常见组织方式、术语稳定性、评价措辞的强弱。

篇幅统计注明口径：正文是否包含图注、表格文字，是否排除摘要和参考文献，汉字数与含英文的字符数是否分开。PDF 提取前去除页眉页脚和重复文本，必要时人工核对。样本很少时给出观察范围而非伪造稳定的平均规律。

根据研究问题与论文类型，将多个范文的合理特征整合成统一规范；只有研究确实同时包含方法与应用时，才融合这两类论证。只学习组织和表达的合理做法，不照搬独特句式、论点、数值或贡献。

## reference.md 只写“应该怎么做”

建议包含以下可执行规范，篇幅和章节按研究需要调整：

1. 研究对象与问题主线：如何定义任务、信息条件和可检验目标。
2. 各章节职责：题名、摘要、引言、任务、方法、实验、讨论与结论分别回答什么。
3. 贡献定位：如何区分新方法、组合改进、应用适配和实验发现。
4. 证据标准：怎样安排基线、消融、统计和主张边界。
5. 图表与公式：何时用架构、流程、连续曲线、数值表及必要公式。
6. 表达规范：自然、具体、克制，少套话，区分观察与解释。
7. 篇幅预算：依据目标期刊和样本给出区间，将主要篇幅留给方法和结果。
8. 正文与补充材料边界，以及文献真实性和最终验收条件。

正文采用“应说明……”“优先采用……”“仅在……时声称……”等规范性句子，不写：

- 原论文的标题、作者、摘要、贡献介绍、实验复述或逐篇评价。
- “论文甲采用……，论文乙体现……”等来源对照。
- 为文章凑字数或凑图数的硬指标。
- 没有条件或执行含义的“逻辑严密、创新突出”等口号。

来源、篇幅测量与提炼依据只保留在阅读笔记中。已有 `reference.md` 时针对不足修订，不整份覆盖。已有规范若与当前有效要求冲突，更新对应规则并保持其他有效内容。
