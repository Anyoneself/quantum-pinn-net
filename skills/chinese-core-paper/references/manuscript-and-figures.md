# 论文正文、图表与交付

写稿、重写、图表修改或交付验收时使用。按用户本次范围选择相应部分。

## 写作与篇幅

从 `reference.md` 读取具体组织与篇幅规范。通用骨架是题名、摘要与关键词、引言、问题定义、方法、验证与结果讨论、结论、参考文献；按研究内容合并或拆分，不机械套章节名。

方法部分解释设计依据、实施过程和核心差异。结果部分逐项回答问题，连起比较条件、主要观察、效应大小、局部差异、解释及成立范围。涉及应用目标时，将其落实到任务、指标和评价条件，不只在引言与结尾出现。

篇幅不足时先查是否遗漏定义、推导、对照、机制诊断和结果分析，再决定补写或补实验。不要用运行清单、泛背景、重复表格数值、套话和大量标准公式充篇幅。目标长度以期刊要求、样本范围和证据量为依据。

## 摘要

摘要通常写成紧凑自然段，遵循以下信息顺序而不强制四个显式小标题：

1. 背景与具体问题：研究对象以及现有方法在什么条件下不足。
2. 工作与贡献：提出、改进或构建了什么，核心设计怎样回应问题。
3. 创新定位与验证：实质差异是什么，用什么数据、对照或任务检验。
4. 实测收益：最重要的定量结果、比较基准及必要条件。

摘要全文不写“具有重要工程价值”“为未来……提供支撑”“具有广阔应用前景”等评价或展望，不仅限于末句。未完成实验、未经验证的应用收益和超出比较范围的“领先”不得写入。

定量结果必须能在正文找到。整体不优于基线时如实说明有支持的局部收益或边界，不虚构正收益来凑摘要结构。已知技术组合、应用适配或新实验发现应准确定位，不能强制命名为理论创新。

存在中英文摘要时，两者的贡献范围、比较对象、数值、条件和关键限制应一致，并与最终结果汇总核对；不能只在一个版本保留负面结果或适用边界。

## 自然、具体、克制

- 用实际对象、操作和结果组织句子，少用“赋能”“深度融合”“全面提升”等空泛表达。
- 比较写清“相对谁、在哪种条件下、什么指标、变化多少”。
- 段落围绕一个问题展开，不整篇重复“首先、其次、最后”或“由图可知”。
- 保持术语稳定，不为换词而变更指标含义，不机械制造长短句。
- 区分观察、解释和假设；没有适当统计依据不写统计意义上的“显著”。
- 限制放在相关方法或讨论位置，摘要和结论仅保留影响理解的关键条件，不在每段重复免责声明。

## 神经网络架构图

研究包含神经网络模型时，正文必须有实际架构图，不能用占位文字、ASCII 示意或未渲染代码块代替；不含神经网络的研究不强加此图。

从实现核对输入、特征处理、主干、分支、融合、输出和训练目标之间的连接。图中采用实际模块的可读功能名称，不预设输入类型、网络架构、约束形式或输出任务。

展示影响方法理解的结构和信息流，省略逐元素向量、密集索引、完整张量形状及装饰性公式。必要变量、核心宽度或维度可在正文或参数表定义，不因图的简化省略方法所需数学定义。

训练期独有的分支或约束与推理路径清楚区分。避免画出实现中不存在的模块或连接。图注说明图中各模块职责和训练推理差异，而不是重复全篇方法。

## 研究流程图

建议提供流程图。涉及模型训练时，交代训练与推理流程；其他研究表达实际的数据采集、处理、分析或验证步骤。流程较短时可与方法图合并，但过程和结构应读得清楚。

使用当前允许且可用的制图工具绘制，并保留可编辑源。若使用生成式图像工具，逐项核对文字和连线，不让视觉生成代替架构核验。

图中交代输入、主要处理步骤、关键决策、验证和输出。涉及训练时，再按实际方法表达前向计算、损失评估、参数更新、停止或模型选择以及推理路径。优化循环与信息依赖要正确，不暗示利用测试集选择模型。避免具体向量展开，使用模块、箭头和短标签。

图像采用统一字体、克制配色、清晰线型及可阅读字号，避免渐变装饰、立体积木和大量无含义图标。

## 图像来源与检查范围

- 示意图与数据图分开管理。数据图来自可核验输出；生成式示意图不得被当作实测结果或模型输出。
- 保留绘图脚本或可编辑源及实际导出格式；位图不能称为矢量图。使用生成式工具时记录工具、提示、修订和人工核对情况，只有位图时明确这一限制。
- 在实际排版尺寸下检查字号、标注、连线、裁切与遮挡；多面板图再检查对齐。矢量PDF的字体、碰撞审计不能套用于没有相应文本结构的PNG，也不能将“不适用”记成“通过”。
- 导出尺寸、分辨率和格式按目标期刊要求选择，不把某次图件的宽度、字号或格式变成通用硬指标。最终导出后实际打开检查，不能只看脚本或中间版本。
- 投稿前核验目标期刊对生成式示意图及辅助工具披露的政策；未指定期刊或未核验时如实说明，不声称已经合规。图像来源与政策记录放在补充材料或交付记录中，不用长篇工具说明干扰正文。

## 结果图以有序曲线为主

| 研究问题 | 优先图形 |
| --- | --- |
| 训练或求解过程 | 损失、误差、残差随迭代或时间的轨迹 |
| 沿有序变量的预测 | 真实值与预测值曲线，并列误差曲线 |
| 条件响应 | 有真实顺序的参数或条件响应曲线 |
| 稳定性和误差分布 | 基于真实样本的经验累积分布或排序误差曲线 |
| 方法与模块总体比较 | 精简结果表；确需图示时保留合理离散表示 |
| 多维分布 | 按数据结构选择分布图、残差图或有意义的截面 |

减少只有少数分类点、重复误差棒、柱状拼贴的主图，不为追求连续外观牺牲数据语义：

- 无序方法名称不是连续自变量，不能把不同模型任意连成曲线。
- 只有少数离散条件时，不用插值伪装密集实验；连接线只是导读时应在图注说明。
- 经验累积分布保留其阶梯性质，不强行光滑化。
- 训练日志可以减少标记或用透明区间表示波动；平滑处理须有依据并披露，保留原始记录，不能隐藏发散或不利阶段。
- 不把事后多项式拟合、生成式曲线或手工绘制轨迹当作实测数据。
- 跨方法或条件保持可比较的轴、单位和色标；不任意截轴扩大收益。

代表性曲线或案例按可解释规则选择，不只展示最有利样本。保留重要的不确定性，但优先采用清楚的区间带、统计表或必要误差条，避免视觉拥挤。

图题、主轴和主要分析应服务于研究问题，不默认突出某一配置参数。次要设置可放入补充分析，但不能隐去决定结论是否成立的条件。

## 正文与补充材料

| 保留在正文 | 主要放入补充材料 |
| --- | --- |
| 数据来源、任务、样本单位及关键划分原则 | 完整分割索引、采样实现和文件清单 |
| 核心方法、必要参数及选择依据 | 全部配置、适用时的初始化种子与逐次运行明细 |
| 必要重复次数、统计方法与不确定性 | 环境版本、依赖列表、执行命令和日志 |
| 主要对照、必要消融、结果与失败条件 | 扩展条件、额外诊断及完整明细表 |
| 效率主张依赖的硬件和计时范围 | 设备与运行环境的完整复现信息 |

补充材料承担复核功能，不把运行审计长篇搬进正文；也不把决定结论是否成立的信息全部藏进附录。

## 修订后的同步与记录

复用并更新已有验收记录，避免另建相互矛盾的报告。简要记录摘要、文献、架构图、流程图及正文与补充材料边界的完成情况和证据位置；不适用项说明原因，未完成项保留缺口。

新增图或替换文献后，同步正文、图注、补充材料中的编号和交叉引用。最后一次文字修订后刷新相应检查及字数、图表数、文献数，注明字数统计口径；这些数量是当前稿件状态，不作为后续论文的固定目标。

明确区分本轮新实验、既有结果复算、原样复用及未重跑测试。自动检查报告只描述实际覆盖项，不以文件存在代替图像检查，也不以格式检查代替证据审查。Markdown更新后，没有同步重建的Word、PDF或其他历史导出件须标为旧版，不冒充当前交付；用户未要求时不必重建它们。

剩余数据来源、独立验证、可比性或图像政策问题，应说明其影响范围。写作要求已满足不等于研究证据已完整，更不等于具备录用保证。

## Markdown 验收

1. 主文件实际存在且内容完整，无空章节、占位图、虚构结果或未替换模板。
2. 摘要、表格和结论数值对应原始汇总，单位、百分比口径和小数精度一致。
3. 每张图由正文引用并有图注；图片实际嵌入，能读清坐标、图例、标签，且无重叠或裁切。表格注明指标方向和统计含义。
4. 适用的架构图与实现一致，流程图与实际研究步骤一致。数学符号首次定义，公式与计算过程相符；涉及代码或训练目标时进一步核对实现。
5. 引用编号连续且双向对应；不少于30篇要求按已核验、充分阅读的去重研究论文检查，不以网页、重复版本或工具文档凑数。
6. 参考文献按目标期刊格式提供真实书目信息与可核验标识。不要将会话内部的搜索编号或临时引文标记写进长期保存的 Markdown。
7. 检查相对图片路径、补充材料链接和必要的数学渲染；用可用预览工具打开稿件，并实际查看本次生成或修改的图。
8. 交付主稿链接，必要时附补充材料链接。说明真实完成的工作与剩余缺口，不用“达到核心期刊发表水平”替代审查结论。
