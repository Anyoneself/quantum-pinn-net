# 中文核心期刊论文写作

基于真实研究材料，写成以研究问题、方法和证据为主线的中文学术论文。风格来自相关核心期刊的实际文章，结论来自可核验的研究结果。减少套话不等于规避检测，不承诺录用，不用润色掩盖研究不足。

根据研究领域、论文类型、输入材料和目标期刊选择具体流程，不预设应用场景、模型、数据类型或目录结构。材料可以是研究方案、数据、实验记录、代码或已有稿件；不存在的实现和结果不能自行假定。

## 先确定本次范围

- 完整起稿或实质重写：执行文献阅读、规范合成、研究材料审查、证据补强、图文写作和最终核验。
- 局部修改：仅处理用户指定的摘要、图表、章节或语言问题。复用已核验材料，不自动开启30篇新文献下载、全量重训或结构重写；发现影响该处结论的问题，应指出并处理。
- 只有计划、建议或评审请求：不擅自改代码、跑实验或修改稿件。
- 尊重当前指令和已有目录、命名、版本，不覆盖无关工作。

完整论文执行以下写作与交付要求，用户本次明确要求或目标期刊硬性规范有冲突时，指出冲突后按有效要求调整；局部修改只核验受影响项，不自动扩大任务：

1. 最终以 Markdown 论文为主交付，不默认生成 Word、PDF 或幻灯片。
2. `reference.md` 只写好文章应如何组织和表达，不放原论文介绍或逐篇摘录。
3. 完整稿引用不少于30篇真实、去重、已阅读相关成果且正文实际引用的论文；保留逐篇来源、实际阅读范围、成果及引用用途，检索条目不等于阅读证据。
4. 摘要说明背景、工作与贡献、实际创新点和实测收益，不写未来展望或空泛的“工程价值”。
5. 研究包含神经网络时，正文必须嵌入与实际实现一致的网络架构图；涉及训练与推理时原则上提供流程图，其他研究按实际方法绘制研究流程。
6. 结果图优先用有意义的连续曲线。架构图和流程图以功能模块与信息流表达，不堆具体向量、张量维度。
7. 种子、环境清单、命令、路径、哈希和逐次运行日志移到补充材料；正文保留判断方法与结论所必需的实验条件。
8. 正文围绕研究问题和主要发现展开，不把次要配置或实现细节当作贡献主线；必要条件简述或放入补充材料，不隐瞒影响结论和比较公平性的信息。

## 按需协作的技能

仅在当前步骤需要且本地可用时读取对应 skill，不全量加载或默认安装。中文表达与章节论证可结合 `research-writing-skill`；论点和证据组织可借鉴 `nature-writing`，但不把中文核心期刊风格改成英文期刊模板。检索、合法全文和书目核对可分别结合 `nature-academic-search`、`nature-downloader`、`nature-ref-verifier`；相关成果理解仍以原文阅读为准。架构、流程和结果图结合 `nature-figure`，计算与实验诊断按需结合 `scientific-toolkit-skill`。没有这些技能时按本 skill 的证据与交付要求继续，不虚称已调用。

## 工作流

### 1. 阅读研究材料

先读研究说明、数据定义、实验记录、结果文件、现有稿件及 `reference.md`；有代码时再读核心实现、实验脚本和测试。辨明研究问题、方法、假设、数据来源、评价标准及已完成工作。不能仅凭名称或概念描述声称采用了某种理论、方法或约束。

区分已验证事实、可检验解释和未完成设想，建立“主张 -> 验证 -> 结果记录 -> 图表 -> 章节”的证据对应关系。现有强基线或负面结果同样纳入。

### 2. 从文献形成写作规范

需要新建或更新风格规范、检索引用时，读 [文献与风格规范](references/literature-and-reference.md)。

通过可用的网页搜索、论文数据库或合法全文工具寻找与研究领域和论文类型接近的优秀中国核心期刊论文，阅读原文，融合与本次研究相适应的组织方式。核验目标期刊要求和收录信息，不凭记忆声称期刊地位。

提炼段落功能、论证顺序、摘要写法、方法展开程度、验证深度、图表分工、篇幅和术语规范，写入 `reference.md`。逐篇阅读笔记、来源和篇幅测量另存，不能混入规范文件。

将风格样本与支撑论点的研究文献分开管理。完整稿中至少30篇研究论文须真实存在、技术概述准确且确实支持正文判断，不能用无关引用补数量。

### 3. 按缺口补实验或扩展模块

证据不足时读 [实验与证据补强](references/experiments-and-evidence.md)。

先明确缺少哪种证据，再选择适合研究类型的补充验证，如对照、消融、响应分析、泛化、稳健性或成本实验，不将所有研究都当作模型训练任务。若现有方法确有可定位的能力缺口，可以提出并实现相关扩展模块；先写可检验假设和比较协议，再试运行、测试与评估，不先宣布创新和收益。

在用户授权及合理本地预算内推进实际工作。昂贵计算、外部资源或超出范围的改动需另行确认。不能运行的实验列为未完成，不能用预测数值或概念曲线充当结果。

### 4. 依据规范和结果写稿

进入写稿或图表修订时读 [论文与图表验收](references/manuscript-and-figures.md)。

先写问题、方法和验证方案，再写结果分析与讨论，最后回写引言、结论、摘要和题名。让“研究问题 -> 方法设计 -> 证据检验 -> 结果解释”贯穿全文；同时包含方法研究与应用验证时，将两者组织在同一论证主线中。

方法和结果承担主要篇幅。内容不足时补论证、诊断和真实实验，不靠种子清单、背景复述、公式堆砌或重复局限性扩字数。使用目标期刊和风格样本导出的篇幅预算，不套用统一的固定字数。

### 5. 核验并交付

按当前范围核对：引用与阅读记录、主张与数据、公式与实现、图与图注、正文数值与原始汇总、链接与文件存在性。生成或修改过的图都应实际打开检查。将未满足要求列出，不把“尚未跑完”写成“完成验证”。自动检查通过只证明其覆盖的记录或数值一致，不替代原文理解、科学判断或投稿审查。

输出位置遵循用户指定或已有材料结构，不硬编码目录。至少区分论文主稿、`reference.md`、文献阅读记录、证据记录、补充材料和图像资源；已有材料承担相应职责时直接复用，不为匹配模板重命名或重复建档。

完整稿的主文件包含题名、摘要、关键词、正文、完整参考文献及论证所需的图表和公式。图像须实际嵌入并配图注。中英文摘要等附加部分按期刊或用户要求提供。

Markdown 内用可移植的图片路径，保留绘图源和原始数据；补充材料记录复现细节。交付消息链接到实际保存的主稿，简述本次完成的实验与图表、未解决问题。不要默认推送代码、投稿、对外分享或生成其他格式。

实质修订后更新已有验收记录，区分本轮新跑实验、复用结果和未重跑检查；同步图号、引用、链接及数量统计。没有更新的历史导出件不得当作最新交付。图像来源、可编辑性、适用的检查范围与投稿政策核验见图表验收规范。

## 完整稿完成条件

- `reference.md` 可独立指导写作，只有规范，不含来源论文介绍。
- 不少于30篇真实研究文献已完成相关成果阅读、去重和引用核对；不足则明确报告缺口。
- 核心贡献有对应验证和可核验结果，实验性主张有真实数据，扩展模块的正负结果均如实处理。
- 摘要有具体背景、贡献、创新定位和经验证的收益，没有展望式宣传。
- 涉及神经网络时，架构图已嵌入；研究流程可读，不以密集向量标注代替模块解释。
- 图表少用无意义离散拼贴，连续曲线不造趋势、不掩盖原始波动。
- 正文有足够的方法与结果分析，运行审计细节已移到补充材料。
- 主稿为可阅读的 Markdown，图、表、公式、引用和资源链接已检查。
