## S2 观测掩码与重复

三次重复标识为101、202、303，同时影响模型初始化、空间划分和噪声。它们不是三个独立数据集；所有运行使用同一批128幅场。

随机缺测每场先确定206个测试点，再确定102个验证点，训练候选按固定随机顺序排列。20%、40%、70%设置依次取204、409、716个训练点，相应训练集互为子集。低观测率下未选位置不参与训练或误差统计。噪声设置保留70%布局，逐场根据训练点标准差生成扰动，并对训练与验证位置同时加噪。

中央缺测的测试掩码为行、列索引9至22，共196点。716个训练点和102个验证点均从方形外选择，10个外部点不使用。验证位置不覆盖方形内部，因而该条件检验的是模型及插值参数依据区域外部观测选择后，在内部的表现。

除预先指定的120轮预算诊断只运行第一个重复外，所有主比较、消融及扰动实验均运行三次。全套预定矩阵包含99组主实验运行和2组延长预算运行，神经网络训练65次，插值参数搜索36次。运行完成情况以 `figures/manuscript_v2/verification.json` 为准。

## S3 结构与优化细节

所有网络输入由坐标2维、标准化条件5维和场嵌入24维组成。条件标准化使用已登记场的外生条件，不使用场值；这是场内补全设置，不适用于未登记新场的直接预测。

周期网络相位通道数6、首层频率18、隐藏宽度128，三层后续残差变换。Fourier 对照采用四个频率和四个两层残差块。网络在CPU上采用4个计算线程和1个互操作线程，批大小8，AdamW的学习率0.001、权重衰减0.00001，梯度范数裁剪上限1，余弦退火，无提前停止，保留验证误差最低的轮次。相同重复内各网络采用相同的场批次顺序，神经元筛选使用独立采样序列。

结构消融均从相同初始化过程出发：

- 无混合：令混合响应为零，保留四组特征槽位，混合矩阵不求梯度。
- 无周期特征：将24维特征全部置零，保留输入维度和正弦首层。相位投影及混合矩阵不求梯度，因此该配置仍是具有周期首层的网络，不能称为“无周期网络”。
- SiLU首层：替换正弦首层激活，保留同一线性层初始化、门控和后续结构，不另外搜索其输入尺度。
- 无门控：移除首层逐元素门控乘积，门控参数不求梯度。
- 无条件输入：将输入中的5个条件通道置零，场嵌入和均值先验不变。它不等同于删除所有工程条件信息。
- 仅数据项：其余三个损失权重均为零，不逐项分离每个正则项的效应。

总参数量包含停用槽位，`trainable_parameters` 按 `requires_grad` 统计。零特征对应的首层列也会失去实际贡献，故上述数字不能代替严格的有效模型容量分析。

## S4 自适应模块

全局动态权重使用每轮末批损失，四项初始权重均为1，倒数损失评分加截断相对改善量，经softmax和0.7/0.3平滑更新。历史中的 `weights_used` 是本轮梯度更新实际使用的权重，而不是轮末为下一轮生成的权重。最后一次更新不会进入新的训练轮次。

局部残差加权使用训练掩码，权重范围1至4，每轮更新。每5轮进行高残差区域检测：候选阈值起于最大残差的0.8倍，逐次乘0.8下调，最多8次，以至少32个候选点为目标；密度邻域半径为2个网格，最少4个点；区域包围框向外扩展1格，覆盖的训练点增加0.2的区域项。它不替换观测点，也不增加标签。

完整组合每轮从独立打乱的加载器抽取4个批次，在前20轮计算首层神经元的平均绝对激活与激活标准差的乘积；低于5%分位阈值的通道重新初始化，标准差为0.12，偏置清零。沿用既有实现，不清空AdamW动量。因此完整组合与动态权重配置的差异包含RBA和重置的共同作用，本文没有将其当作MC的独立效应。

## S5 插值、残差校正与计时

IDW用 `scipy.spatial.cKDTree` 查询近邻，参数为近邻数4、8、16与距离指数1、2、3。查询恰好位于训练点时直接返回观测。RBF用 `scipy.interpolate.RBFInterpolator`，核为 `thin_plate_spline`，包含一次多项式项，坐标归一到单位正方形，候选近邻数16、32、64，平滑参数0、0.01、0.1。各条件分别在全部验证点上选择一组公共参数，并保存全部候选误差，未按每幅场单独调参。

残差校正固定8近邻、距离指数2、强度0.95，不使用插值选型结果再次调整。所有网络均保存原始输出和校正输出，只有训练位置被替换为观测；验证位置不回填真实值。

网络训练计时包含逐轮验证、自适应更新及检查点内存复制，不包含最终预测、模型文件写盘和后处理。插值的“搜索时间”包含9组参数的整场预测与验证评分。另记录一次所选参数的整场预测时间。这些时间是本机任务期间的运行记录，不是排除后台负载影响的专用硬件基准。

120轮实验重新从初始状态训练，并把余弦退火周期设为120轮；不是在40轮已退火到终点的模型上直接续训。该对照同时改变训练总量与学习率历程，只有一次重复，用于提示预算敏感性，不支持稳定的最终性能排序结论。

## S6 相对流动求解

对每个输入场先减去本场均值，再作指数映射。将32×32数组视为单位正方形上的单元常值相对渗透率。内部面传导率采用调和平均并乘面长/中心间距，左、右边界面采用半单元距离，对应压力1和0；上下边界通量为零。

求解器使用 SciPy 的 `spsolve`，以双精度计算。均匀场单元中心压力应满足 \(p_j=1-(j+1/2)/W\)，积分入口通量为1，相关单元测试同时检查压力、通量及离散残差。不同场的结果均记录最大方程残差和入口、出口不平衡率。

相对渗透率转换分别使用参考场和预测场各自的均值，不将参考均值提供给预测场。因此流动诊断关注去均值后的结构差异，无法反映真实尺度不确定性。它也不以未知点的压力标签反向约束训练。

## S8 运行与检查

训练入口：

```bash
python gen-figures/run_supplement_v2.py --extended
```

```bash
python gen-figures/analyze_supplement_v2.py
python -m unittest discover -s tests -v
python gen-figures/verify_supplement_v2.py
```

检查覆盖掩码互斥与嵌套、隐藏测试值不影响观测和先验、隐藏位置不影响插值和残差校正、各结构梯度有限、均匀场解析响应，以及全部保存预测的指标重算。图表另执行面板对齐、PDF字号和文字碰撞检查，并作人工图像检查。运行结束后的量化检查结果保存在图表目录。
