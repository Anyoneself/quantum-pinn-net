# V3 配对补充实验方案

固定日期：2026年10月21日。方案在新增训练前确定；已有六场结果已知，因此本轮为后续复验，不追溯描述为独立注册研究。

## 问题与证据职责

主要问题是在相同配置的新独立场上，量子特征相对当前Tanh特征块的平均重建收益能否复现。另以单因素条件检验观测数量、噪声和场空间结构下的适用范围，不预设各条件均占优。

原研究的411、422、433、444、455、466六场保持冻结、单独报告，不进入本轮主检验，也不与300轮主实验混合。

变化条件复用第一组的场种子以支持配对检查，但不同条件不计作新增独立场。总计24个新独立场、48个场与条件组合。每个组合固定使用101、202、303三次划分与初始化重复，两种架构共288次训练。

其余沿用[原方案](PROTOCOL.md)：1000轮Adam、CPU float64、单线程、关闭RBA和MC，保存0、100、300、1000轮及验证最优模型；使用默认网络、损失、物理点、验证点和边界条件。只按验证观测损失选模。测试标签不参与训练、挑场、超参数或轮次选择。

`noise=0.1`表示给训练和验证的自然对数渗透率观测加入零均值高斯噪声，标准差为该次训练位置真实对数渗透率标准差的10%；不是对渗透率值加10%相对噪声。尺度不使用验证或测试位置统计量，评价仍使用无噪声参考场。

更稀疏条件的训练、验证与测试划分按现有`observe`规则重新生成；不把不同条件的误差差异单独归因于训练点数，因为验证和测试位置也可能变化。场内经典与量子模型始终共享相同划分。

## 主终点与统计

主终点固定为验证最优模型的留出渗透率相对L2误差，比较方向为量子减经典。每场先平均三次重复，再以场为单位统计，不把训练重复或不同条件当作独立场。

主检验使用四个同配置组的全部24个新场；四组分别给出完整描述性结果，不按组表现选择合并。四种变化条件各自按六场统计，不与主复验混合。五项预设比较均报告场级配对差值、均值相对降低、20000次场级百分位bootstrap区间及双侧精确符号翻转p值。24场使用SciPy分批枚举全部2^24种符号；其他组沿用原六场算法和固定bootstrap种子20261016。

五项比较构成同一检验族，另报告Bonferroni调整p值`min(1, 5*p)`，以调整后p<0.05且差值为负作为本轮统计支持判据。bootstrap区间为未作多重性调整的探索性区间，不以区间代替校正检验。符号翻转依赖场级差异的对称/交换性假设；给出完整差值和不确定性，不由p值推导收益大小或普遍优势。

压力、独立PDE残差、下游通量、训练耗时和NTK为次要或诊断指标，完整保留，不据此更换主终点。各条件比较的是各自经典/量子模型，不把跨条件均值变化解释为已证实的因果机制。这里没有新增更强周期基线、等参数、等时间或无纠缠消融，结论限定于既定对照。

## 执行与核验

由[批量入口](run_supplement.py)先写入完整`plan.json`、方案及源码快照，再启动子进程。所有路径以仓库位置解析；输出限定在`v3/ntk/runs/`，不覆盖已有目录。每组独立归档，失败留存并报告，不替换种子或只统计完成且有利的子集。八组全部完成并核验后才生成总报告。

可并行运行独立组，进程内训练和BLAS均单线程；并行耗时受资源共享影响，不作为独占机器的等墙钟性能比较。保存每组全部检查点，逐组核验哈希、选模、预测指标、J乘积、核谱和分组加和，并对首场首次重复的初始及最佳权重重新自动微分。

在仓库根目录运行：

```bash
PYTHONPATH=v3/src .venv/bin/python -B v3/ntk/run_supplement.py --output v3/ntk/runs/supplement_20261021 --workers 4
```

`--smoke`运行八组缩小配置，每组一个场、一次重复、两轮训练，共16次训练；只验证流程，不用于科研结论。研究配置和流程检查分别存放，不混合统计。
