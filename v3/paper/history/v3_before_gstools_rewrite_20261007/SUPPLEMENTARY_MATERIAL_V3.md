# 补充材料：量子特征增强 PINN 的渗透率场反演

> 本材料对应历史三角级数场与压力监督实验，不是当前默认GSTools、仅渗透率监督实验的参数或结果。以下复现实验命令已明确添加历史协议选项。

对应主稿：`paper/QUANTUM_DARCY_PINN_MANUSCRIPT_V3.md`。整理日期：2026-10-07。

本材料只对应 V3，复用已完成的72次训练，不与 V2 的场补全数据、Fourier 对照或插值校正结果混合。

## S1 数据、划分与参考求解

| 项目 | 归档设置 |
| --- | --- |
| 无量纲区域 | \([0,1]^2\)；\(k_{\rm ref}=\mu=L_{\rm ref}=\Delta p_{\rm ref}=1\) |
| 参考场种子 | 11、22、33，依次对应正文场1-3 |
| 每场重复种子 | 101、202、303 |
| 观测网格 | 24×24单元中心 |
| 压力参考网格 | 72×72；奇数倍细化使粗细单元中心重合 |
| 频率 | \(f_x,f_y\in\{1,2,3,4\}\)，共16个正弦乘积项 |
| 系数 | 独立正态随机数除以 \(f_x^2+f_y^2\)，再使绝对值和为0.6 |
| 两方向相位 | 各自均匀分布于 \([0,2\pi)\) |
| 常数对数项 | 均匀分布于 \([-0.15,0.15]\) |
| 每种变量训练/验证/测试位置数 | 48/24/504 |
| 噪声 | 0；软件支持噪声不意味着本文做过噪声试验 |
| 域内训练配置点 | 128，固定均匀随机点 |
| 无流训练边界点 | 上、下各32，共64 |
| 测试物理配置点 | 128个独立随机点，坐标保存于各次 `observations.npz` |
| 场级统计 | 先在每个场内平均3次拟合，再检查场间方向 |

压力参考采用单元中心有限体积离散，单元面传导率为调和平均，左右边界考虑半单元距离。压力观测取细网格对应中心值，不插值。每场 `reference.json` 保存生成参数、细网格求解残差、通量平衡及粗细差异。数据生成没有使用完整场均值或方差作标签标准化。

两类观测各自划分，因此某位置可属于渗透率测试而属于压力训练。这是允许的信息结构：模型可以利用已知压力推断该处渗透率；不能将这种跨变量信息解释成只使用渗透率观测的任务。每种变量内部的训练、验证、测试集合互斥。

## S2 模型、训练与筛选

| 项目 | 设置 |
| --- | --- |
| 渗透率编码器 | Linear(2,24) → Tanh → Linear(24,4) |
| 角度映射 | \(\pi\tanh(\cdot)\)，输入坐标先映射至 \([-1,1]^2\) |
| 经典特征块 | 两层 Linear(4,4) + Tanh |
| 量子特征块 | 4量子比特；初始 RY 编码；2层 Rot + CNOT |
| 每层纠缠顺序 | 0→1、1→2、2→3、3→0 |
| 量子读出 | 四个 Pauli-Z 期望值 |
| 共同渗透率读出器 | Linear(4,24) → Tanh → Linear(24,1) |
| 压力网络 | 2→24→24→1，两个 Tanh 隐藏层；硬编码左右压力边界 |
| 总参数量 | 经典1054，量子1038 |
| 特征块参数量 | 经典40，量子24 |
| 压力网络参数量 | 两组均697 |
| 量子模拟与导数 | `default.qubit`，`shots=None`，Torch `backprop` |
| 数值精度与线程 | CPU float64；1线程 |
| 优化器 | Adam，学习率0.001，无学习率调度 |
| 训练预算 | 每次300轮，不提前停止；验证选择最佳检查点 |
| 梯度裁剪 | 总范数上限5 |
| 全局损失权重 | 对数渗透率10、压力10、方程1、上下边界1 |
| 模型选择 | 全部验证对数渗透率与压力误差的加权和；包括第0轮 |
| RBA | 20轮预热后启用；衰减0.9、增益4、分母下限 \(10^{-12}\) |
| MC时序 | 20轮预热后，每20轮一次；首次第40轮 |
| MC子批次 | 4次试验；每类最多32点；每次类内无放回抽样 |
| MC候选 | 平均相对损失增量最低25%；少量通道时至少考虑一个 |
| MC条件 | 均值+2倍标准误不高于0.01；至少保留2个特征 |
| MC额外接受条件 | 完整验证观测评分不增加 |
| 筛选后状态 | 只改掩码；不重置网络参数或Adam状态 |

共同编码器与读出器使用 `seed+11` 的独立随机作用域，特征块使用 `seed+23`，压力网络使用 `seed+37`，筛选子批次使用 `seed+5009`。这种分离保证特征块参数数量变化不会改变共同层的初始化。观测与初始化在同一重复中使用同一基础种子，尚未交叉设计分离二者贡献。

同一场、同一重复中八种方法使用相同数据和预算，但不同特征块的参数量、表示族和运行时间不同。本文不存在等墙钟预算、系统验证调参或扩展经典表示对照。
