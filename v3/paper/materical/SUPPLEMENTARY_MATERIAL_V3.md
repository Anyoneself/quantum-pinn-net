## S2 网络、损失与训练配置

### S2.1 网络实例

| 模块 | 实际结构 |
| --- | --- |
| 坐标映射 | \(2(x,y)-1\) |
| 渗透率编码器 | Linear(2,24) → Tanh → Linear(24,4) |
| 角度映射 | \(\pi\tanh(\text{编码结果})\) |
| 经典特征块 | 两层 Linear(4,4) → Tanh |
| 量子输入 | 4比特初始零态，各比特施加一次 RY 编码 |
| 量子可训练层 | 两层，各层每比特一个三角参数 Rot 门 |
| 每层纠缠门顺序 | CNOT 0→1、1→2、2→3、3→0 |
| 量子特征输出 | 四个 Pauli-Z 期望值 |
| 特征掩码 | 4维二值向量，初始全1 |
| 渗透率读出 | Linear(4,24) → Tanh → Linear(24,1) |
| 渗透率最终值 | 对数输出的指数，不后处理校正 |
| 压力原始网络 | 2→24→24→1，两层 Tanh 隐藏层 |
| 压力最终值 | \(1-x+x(1-x)N_p(2(x,y)-1)\) |
| 量子后端 | `default.qubit`，`shots=None` |
| 可微接口 | Torch，`diff_method="backprop"` |

| 部分 | 经典 | 量子 |
| --- | ---: | ---: |
| 渗透率编码器 | 172 | 172 |
| 特征块 | 40 | 24 |
| 渗透率读出 | 145 | 145 |
| 压力网络 | 697 | 697 |

编码器与读出使用 `seed+11`，特征块使用 `seed+23`，压力网络使用 `seed+37` 的独立随机作用域。读出末层权重初始化标准差0.05，偏置为0。MC 随机数发生器使用 `seed+5009`。各模型独立优化，对应初始化相同不等于共享训练参数。
