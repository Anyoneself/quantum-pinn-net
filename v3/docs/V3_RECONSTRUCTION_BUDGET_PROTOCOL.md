# V3 渗透率重建：训练预算诊断

记录日期：2026年10月7日。本文在本轮训练开始前记录实验范围，不把后续检查当作独立预注册研究。

## 问题与假设

当前图4来自300轮预算、三个GSTools场、首次重复101的最佳验证模型。六个基础模型中五个的最低验证误差出现在第300轮，另一个为场33的经典模型、第82轮。原场包含的局部高低渗透率结构在预测中恢复不足。工作假设是短训练预算可能造成欠拟合；仅凭这一现象不能断定增加轮数一定有效。

## 固定比较

- 旧归档：`v3/experiments/quantum_pinn_v3_gstools_konly_20261007`，只读保留。
- 新归档：`v3/experiments/quantum_pinn_v3_reconstruction_budget_20261007`。
- 使用全部三个原有场11、22、33，重复101，不按重建质量挑场。
- 同时重训`classical_plain`与`quantum_plain`，共六次拟合。
- 唯一配置变更为训练预算300→5000轮；均从同一规则初始化重新训练，不从最佳检查点重启Adam。
- 原有48个渗透率训练观测、24个验证观测、504个测试位置、物理点、边界点、模型结构、学习率及损失权重保持一致；压力仍无观测监督。
- 仍按最低验证观测损失选择检查点，包含初始状态；测试误差和图像相似性不用于选择轮次。
- 暂不调RBA或MC阈值，也不添加Fourier编码、参考场残差补偿、插值模型或其他新模块。

## 核验与解释边界

训练后逐数组核对新旧参考场、观测划分和物理点；逐记录核对前300轮轨迹应与旧归档一致。读取全部六次拟合的验证选模结果，统一评价留出误差、空间形态及物理残差，保留改善和退化结果。

本实验由查看原测试图后提出，是同一数据上的探索性预算诊断，不是未接触测试集的外部确认。只有一次重复，不能替代原论文八组、三个重复的主比较，也不能将预算收益归因于量子模块。若使用新图，必须明确其预算和范围，并与旧预算结果区分。

定量图仅从保存的模型预测绘制。原场、经典预测、量子预测共用色标，不平滑、不截断、不混合参考场，不独立归一化预测图。没有达到的重建质量如实报告。
