# V3：GSTools 渗透率观测下的量子特征增强 PINN

当前默认协议：GSTools 新生成场，只使用渗透率观测监督；压力参考仅用于训练后的评价。
当前叙事更新于2026年10月19日：以量子特征的平均重建收益为核心，三场主对照降低9.00%，六个新场的另一1000轮协议降低15.23%；两批分别统计，后者为描述性补充证据。RBA降低独立残差24.07%，作为物理目标调节的次级发现。

## 1. 核心问题与证据分工

稀疏观测需要恢复未观测位置，核心问题是可训练量子特征在给定轮数内能提供怎样的重建收益。
Darcy双网络将渗透率与辅助压力耦合，在固定接口比较经典与量子特征，分离表示与策略贡献。

| 证据 | 论证职责 | 呈现位置 |
| --- | --- | --- |
| 三场300轮交叉对照 | 确定9.00%平均重建收益的模块归属 | 主结果 |
| 六个新场1000轮基础组 | 检查另一组场与预算下的平均重建方向，降低15.23% | 描述性补充证据 |
| RBA独立点残差 | 确定物理目标调节作用，降低24.07% | 次级发现 |
| MC配对及掩码日志 | 区分表示收益与读出筛选贡献 | 适用性对照 |
| 空间图、预算、FVM及时间 | 检验局部恢复、优化时长、下游用途和实现代价 | 必要支持与使用条件 |

V1/V2 的 `StandardPINN` 和 `QuantumFeaturePINN` 不作为新路线的实现基础：
历史正式实验未使用局部 Darcy 训练约束，历史量子启发特征也不是量子线路。
它们的代码、论文和结果原样保留，不能与 V3 指标合并。

## 2. 明确物理问题和观测

使用单位正方形上的无量纲稳态单相 Darcy 系统：

```text
k = exp(log_k) > 0
q = -k * grad(p)
div(q) = 0
p(0,y) = 1, p(1,y) = 0
q_y(x,0) = q_y(x,1) = 0
```

这里黏度、长度、渗透率及压差参考尺度均取1。该设置是明确的合成问题，不是对历史
归一化数组的逆变换，不声称具有现场单位或产量意义。

渗透率参考场由 GSTools 1.7 的 `Gaussian` 协方差模型和 `SRF` 生成。
默认自然对数场均值为0、方差为0.4、相关长度为0.25、各向异性比为0.6、
旋转角为0，采用 `RandMeth` 生成器的1000个模态。参数在实验前固定，
保存库版本、种子、协方差参数、生成器与模态数。
该库生成器自身采用随机化谱表示，不能把“使用GSTools”描述成完全不涉及谱模态；
它不同于首轮代码手工固定频率集合的有限正弦乘积级数。

定义 `log_k=SRF(x,y)`、`k=exp(log_k)`，不使用完整场的样本均值、方差或极值
进行归一化和裁剪。这些是预先指定统计参数的无量纲场，不是对现场渗透率统计的拟合。
本次不直接复用 V2 已经裁剪的归一化数组，不把它们当成具有原始物理尺度的渗透率；
两版使用同一数据生成工具，不代表相同数组、后处理或可直接比较的任务。
每个场独立生成；每次训练只恢复该场，重复运行不表示无需适配的新场泛化。

粗细网格使用同一个 GSTools 场实现：先计算细网格场值，再抽取重合中心。
独立有限体积求解器在更细网格上生成仅用于评价的压力。使用奇数倍细化，使粗网格中心恰好落在
细网格中心；内部传导率使用调和平均，左右边界使用半单元距离。参考档案记录
求解残差、通量平衡、粗细网格压力和通量差。默认三倍细化不是完整的网格收敛证明，
正式研究应继续增加细化级别，检查结论对离散误差是否敏感。

渗透率划分为互斥的训练、验证、测试位置，默认48个训练点、24个验证点，
其余网格点为测试点。所有八组方法使用同一划分。压力训练和验证观测均为空，
全部压力参考只参与最后的评价，不参与损失、MC接受或检查点选择。
训练仍使用预先指定的压力边界条件；“仅渗透率观测”不是完全没有物理先验。

`--p-train` 大于零会显式启用额外压力监督，必须作为另一种观测协议报告。
`--field-generator trigonometric` 仅保留旧生成器以便历史比较，不是当前默认路径。

可选噪声加在实际存在的训练与验证观测上，尺度只来自该变量的训练点标准差。
渗透率观测噪声作用于 `log_k`，不是直接对 `k` 添加高斯噪声。
隐藏位置参考值不参与先验标定、训练、筛选或选模。
少量观测和单一流动工况不保证反问题唯一可辨识；结果仅表明当前先验结构和观测下的恢复效果。
特别是没有压力观测时，不同正渗透率场可以对应满足相同边界条件的不同压力解，
因此 Darcy 一致性本身不能唯一确定渗透率，也不能预设其优于纯数据重建。

## 3. 模型和真实量子特征

压力网络是辅助未知场表示，经典与量子组使用相同结构和初始化的 Tanh MLP，输出采用：

```text
p(x,y) = 1-x + x*(1-x)*MLP_p(x,y)
```

该形式精确满足左右压力边界；上下无流通过训练残差约束。
渗透率网络输出 `log_k`，指数映射保证正渗透率，不作逐场中心化或标签极值裁剪。

两种渗透率网络的共同路径：

```text
(x,y) -> common encoder -> pi*tanh(encoded)
      -> interchangeable feature block -> feature mask -> common readout -> log_k
```

- 经典特征块：相同输入/输出维度的 Tanh 全连接层。
- 量子特征块：默认4个量子比特、2层线路。RY输入编码后，每层包含可训练Rot门和
  CNOT纠缠连接，输出各量子比特的Pauli-Z期望值。
- 后处理筛选只屏蔽测量特征，不剪除量子比特或改变线路拓扑。
- 共同输入层、输出层和压力网络使用独立、固定的随机流初始化；量子块的参数数量
  不会改变其他层的初始化。

线路由 PennyLane `default.qubit` 执行，`shots=None`，Torch接口和`backprop`求导。
训练需要坐标导数及其对参数的混合导数，不能使用破坏计算图的 NumPy 转换。
单元测试将量子门参数的 PDE 损失梯度与中心有限差分比较。

主实验是精确状态向量模拟，不包含有限shots、设备噪声或硬件运行。
模拟器反向传播成本不同于真实硬件的梯度估计成本。记录的QNode调用和样本求值数
不包括真实设备shots，也不是完整的量子硬件资源估计。

经典特征块与量子块具有相同接口，但不保证严格相同参数量。结果报告各块参数量。
当前矩阵控制训练轮数，不等价于控制墙钟时间；正式效率结论仍需等参数容量和
等计算预算对照。只有这种受控比较通过后才讨论量子表示的额外价值。

## 4. PINN目标和RBA

```text
L = 10*mean((log_k_pred-log_k_obs)^2)
  + weighted_mean(div(-exp(log_k_pred)*grad(p_pred))^2)
  + mean(q_y_at_top_bottom^2)
```

这些固定权重是预先声明的起点，不是验证过的最优配置。
所有方法使用相同权重、Adam学习率、梯度裁剪、CPU双精度和训练预算。
当前压力观测项关闭，其权重为0。只有显式启用压力监督时才加入该观测项，权重为10。
默认验证评分仅由渗透率验证误差构成，不使用压力参考或测试误差选择检查点。
包括初始模型在内，保留验证评分最小的检查点及其特征掩码。

RBA仅改变固定配置点的方程残差权重，不改变采样位置，也不重写全局损失权重：

```text
a_i <- gamma*a_i + (1-gamma)*abs(r_i)/max(max_j(abs(r_j)), epsilon)
w_i = 1 + gain*a_i
L_physics = sum(w_i*r_i^2)/sum(w_i)
```

权重更新使用detach后的训练残差。单位下限避免放弃低残差位置；
归一化避免额外改变方程项的总体尺度。默认先训练20轮，再启用RBA。
这是具有单位下限和归一化的RBA启发变体，不宣称逐式复现原论文全部配置。
RBA通过共同损失作用于压力、渗透率和量子门参数，不是独立量子算法。

## 5. 蒙特卡罗阈值筛选

默认预热20轮后每20轮筛选一次，4次随机子批次、每类最多32个点。
每次随机抽取渗透率训练观测、方程配置点和无流边界点，不读取压力参考或测试标签。

对每个当前保留的特征，计算：

```text
utility_j = (L_with_feature_j_masked - L_current) / max(abs(L_current), epsilon)
```

同一试验内所有候选使用同一组点和冻结的RBA权重，形成配对比较。
跨试验计算均值和 `mean + 2*standard_error` 的保守评分。
该评分是工程启发式，不解释为严格的独立样本置信区间。

默认仅考虑贡献最小的25%特征，且保守评分不高于0.01；至少保留2个特征。
候选掩码还必须不增加完整验证观测评分，才实际应用。没有通过条件的特征则不筛除。
通道数很小时，单次至多候选比例会向上保留至少一个候选，但最低特征数优先。
阈值固定记录在配置里；不对测试结果搜索阈值。

筛选接受后继续训练，不重置量子门、不重置经典神经元、不改变Adam动量。
训练、验证和筛选的随机流分离。经典模型采用同样的特征筛选规则。
特征屏蔽未减少线路执行次数，不能把保留特征更少解释成量子线路计算加速。
筛选成本计入训练时间，并单独报告。

这是待检验的“MC配对特征消融+阈值+验证接受”策略，不是已有量子优势的证明。

## 6. 受控实验矩阵

| 特征块 | 不加增强 | RBA | MC | RBA+MC |
| --- | --- | --- | --- | --- |
| 经典 | classical_plain | classical_rba | classical_mc | classical_rba_mc |
| 量子 | quantum_plain | quantum_rba | quantum_mc | quantum_rba_mc |

默认3个生成场、3次观测划分/初始化重复，共72次逐场训练。
初始化与观测掩码在同一重复内使用固定种子，尚未通过交叉设计分离二者不确定性。
主要报告测试位置的相对渗透率L2与log_k RMSE。压力RMSE是对无压力监督辅助网络的
训练后评价，不应描述为压力观测拟合精度。

物理评价包括独立配置点上的PDE残差、无流边界残差、网络自身的入口/出口通量，
以及把预测渗透率交给独立FVM后的下游响应。
后者与相同粗网格下的真实渗透率响应比较，避免把粗细离散误差归给网络；
网络压力预测另与细网格生成的压力参考比较。
网络通量守恒和下游FVM求解器守恒分别报告，不能混为一个指标。

主比较不使用IDW残差校正，避免把插值收益归给量子模块。
未来若增加空间插值或纯数据基线，需使用同一组渗透率观测和评价位置。

汇总保留同一场、同一重复的配对差值，也先在同一场内平均后报告场级结果。
跨运行标准差仅作描述，不将空间点或同一场的重复当成独立数据集。
单次或短预算运行不用于判断显著性、最终收敛排序或发表成熟度。

- `manifest.json`：配置、运行环境、状态、代码及全部产物哈希。

## 9. 历史首轮核验记录（2026-10-07，不是GSTools新结果）

实际归档为 `v3/experiments/quantum_pinn_v3_initial_20261007/`，配置在实验开始前固定，
使用手工三角级数生成器并同时监督渗透率与压力。以下数字不适用于当前默认协议。
使用3个生成场、每场3次观测划分/初始化重复、8种方法，每次300轮，共72次训练。
没有依据测试误差修改此次阈值或筛选场。结果入口为该目录下的 `REPORT.md`。

9次运行平均的测试渗透率相对L2误差如下，越低越好：

| 配置 | 经典特征 | 量子特征 |
| --- | ---: | ---: |
| 不加增强 | 0.105710 | 0.102443 |
| RBA | 0.106315 | 0.103364 |
| MC | 0.106312 | 0.101942 |
| RBA+MC | 0.106469 | 0.103363 |

量子基础模型比经典基础模型平均降低约3.09%，但压力RMSE从约0.00826增至0.01056，
PDE残差RMSE从约0.09385增至0.12323，平均训练时间从约0.83秒增至6.65秒。
不能把单个场值指标的小幅改善写成综合性能或计算效率优势。

量子MC配置在此矩阵中的平均场值误差最低；量子RBA+MC未进一步改善量子基础模型的
场值误差，但平均PDE残差从约0.12323降至0.11503。物理约束满足程度和反演精度
必须分别讨论。筛选日志保存候选、接受/拒绝及最佳检查点实际使用的掩码；
后期接受了筛选，不意味着验证选中的较早检查点也使用了该掩码。

多次运行在预算结束时仍取得最好验证分数，也有运行较早达到验证最优，
尚不能认定所有方法充分收敛。没有做参数搜索、显著性检验或真实硬件实验。

本次完成的检查：

- 全部30项新旧单元/集成测试通过，未修改历史训练实现。
- 非均匀解析Darcy解的有限体积误差在16、32、64网格下呈二阶下降。
- 72次归档复核通过，检查386个产物及11份源代码/依赖快照文件的哈希。
- 单独重载首个场、首个重复的8个检查点，重新预测场值、重新自动微分PDE残差，
  与保存数组在 `1e-12` 容差下相符。这不是72次训练的独立重跑。
- 依赖检查和 `git diff --check` 通过。现有V2稿件和架构图的用户修改未被覆盖。
