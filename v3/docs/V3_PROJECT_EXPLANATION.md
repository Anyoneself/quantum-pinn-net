# V3 项目说明：量子特征改善稀疏渗透率重建

叙事更新：2026年10月19日。三场主对照、预算诊断及六场补充实验分别引用各自归档。

本文以平均场值重建收益为主线，说明问题、特征表示、配对证据和配置选择。实现细节依据源代码、配置及逐次结果展开；方程残差、流动响应和模拟时间分别承担物理目标、下游适用性和成本评价职责。

## 1. 核心发现与研究问题

当前项目研究的问题是：

> 在相同稀疏观测、外部网络结构及训练规则下，可训练量子特征能否改善未观测位置的渗透率恢复？

关键证据分为三个层次：

| 论点 | 实验职责 | 已有结果 |
| --- | --- | --- |
| 量子特征改善平均重建 | 三场、300轮、八组交叉对照分离表示与策略 | 基础Q对C的平均留出误差降低9.00% |
| 表示收益具有另一组场级证据 | 六个新场、1000轮、关闭RBA/MC的配对实验 | 平均误差降低15.23%，六场中五场场内平均更低；描述性支持 |
| 残差加权调节物理目标 | Q+RBA对Q的独立配置点评价 | 方程残差降低24.07% |

思路是在Darcy双网络中用经典压力表示辅助未知场，在渗透率路径的固定接口替换特征模块。这样，稀疏渗透率观测与物理约束共同训练模型，无需增加域内压力标签。MC作为筛选适用性对照，不作为基础重建收益来源。

任务是**合成场上的逐场重建**，每个场均重新拟合。不同协议不混合统计；结果针对所设Tanh基线和各自固定轮数，运行后再以独立参考评价场值、物理目标和实现代价。

## 3. 输入、监督和输出分别是什么

### 3.1 最容易混淆的三个概念

| 概念 | 当前项目中的内容 | 不应混淆为 |
| --- | --- | --- |
| 网络前向输入 | 单个空间位置的二维坐标 \((x,y)\) | 完整渗透率矩阵、压力图像或工程条件向量 |
| 数据监督 | 少量位置上的 \(\log k\) 观测值 | 全场真实渗透率或压力观测 |
| 主要预测输出 | 任意查询位置的 \(\widehat{\log k}\)，进一步得到 \(\hat k=\exp(\widehat{\log k})\) | 不经重新训练的新场预测 |
| 辅助输出 | 压力网络给出的 \(\hat p(x,y)\) | 额外输入的实测压力 |
| 物理先验 | Darcy 方程和预设边界条件 | 从参考压力中提取的训练标签 |

因此，“只有渗透率数据”准确地说是：**只有渗透率场值作为观测监督，但网络输入仍是坐标，训练还使用方程和边界先验。**

### 3.2 总体数据流

```text
预设协方差参数 + 场随机种子
    |
    v
GSTools 生成自然对数渗透率场 log_k
    |
    +--> exp(log_k) 得到正渗透率场 k
    |        |
    |        +--> 独立有限体积求解器 --> 参考压力
    |                                  |
    |                                  +--> 仅用于训练后评价
    |
    +--> 划分渗透率观测位置
             |
             +--> 48个训练点 --> 渗透率监督损失
             +--> 24个验证点 --> 特征筛选接受、最佳模型选择
             +--> 504个测试点 --> 最终渗透率误差

空间坐标 + 已知方程 + 已知边界
    |
    v
经典 PINN 或量子特征增强 PINN
    |
    +--> 渗透率预测
    +--> 辅助压力预测
    +--> 自动微分得到通量、方程残差、无流边界残差
```

每个场都从新初始化开始训练。这里没有跨场预训练，也没有用前一个场的参数去直接预测后一个场。

## 4. 数据如何生成

### 4.1 计算区域和单位

计算域为单位正方形：

\[
\Omega=[0,1]\times[0,1].
\]

渗透率、黏度、长度和压差参考尺度均取1，整个问题采用无量纲形式。结果不能直接解释为某个油藏的毫达西渗透率、实际压力或产量。

### 4.2 GSTools 的实际配置

| 配置项 | 本次值 |
| --- | --- |
| 库版本 | GSTools 1.7.0 |
| 空间维度 | 2 |
| 协方差模型 | `Gaussian` |
| 随机场生成器 | `SRF`，内部生成器为 `RandMeth` |
| 自然对数场均值 | 0 |
| 自然对数场方差 | 0.4 |
| 相关长度参数 `len_scale` | 0.25 |
| 各向异性参数 `anis` | 0.6 |
| 旋转角 | 0弧度 |
| 随机谱模态数 `mode_no` | 1000 |
| 场随机种子 | 11、22、33 |
| 观测噪声 | 0 |

实现关系为：

\[
\ell(x,y)=\operatorname{GSTools.SRF}(x,y),\qquad
k(x,y)=\exp(\ell(x,y)).
\]

其中 \(\ell=\log k\) 使用自然对数，不是以10为底的对数。

这里的0和0.4是预设随机场统计参数，不要求每个有限网格实现的样本均值、样本方差恰好等于它们。项目没有读取完整场的样本均值、方差或最大最小值，再进行逐场归一化或裁剪。

GSTools 的 `RandMeth` 本身采用随机谱模态表示，不能说它“完全不涉及 Fourier 或谱方法”。它与旧 V3 手工固定频率集合的有限正弦乘积级数，不是同一套生成实现。

配置文件仍保留 `modes=4` 和 `log_amplitude=0.6` 两个历史参数；当前选择 `field_generator="gstools"` 时，它们不参与 GSTools 场生成，不能误写为本次随机场的有效配置。

### 4.3 粗细网格使用同一个随机场

正式实验评价网格为 \(24\times24\)，共有576个单元中心。

数据生成先在 \(72\times72\) 细网格计算一次 GSTools 场，再抽取与粗网格中心重合的位置，得到 \(24\times24\) 的 \(\log k\)。细化倍数为3，重合关系由单元中心坐标保证。

```text
同一个 GSTools 场实现
    |
    v
72 x 72 细网格 log_k
    |
    +--> 指数变换 --> 细网格 k --> FVM --> 细网格压力
    |                                            |
    |                                            +--> 抽取重合中心 --> 参考压力
    |
    +--> 抽取重合中心 --> 24 x 24 log_k --> 划分监督和测试位置
```

这不是分别生成一个粗场和一个细场，也不是对不同随机场的结果进行比较。

### 4.4 参考压力怎样得到

独立有限体积法（FVM）求解器使用单元中心离散：

- 内部相邻单元面的渗透率取调和平均。
- 左右压力边界按半个单元距离计算传导关系。
- 上下边界为无流边界。
- 解稀疏线性方程组得到压力。
- 保存离散方程残差、入口出口流量平衡以及粗细网格差异。

参考压力的存在是为了评价辅助压力预测，不意味着训练读取了它。

本次三个场的数值参考检查如下：

| 场种子 | 粗网格 \(k_{\max}/k_{\min}\) | 粗细网格压力 RMSE | 粗细网格入口通量相对差 |
| --- | ---: | ---: | ---: |
| 11 | 10.442470 | 0.00038403 | 0.00080368 |
| 22 | 11.835420 | 0.00030281 | 0.00091034 |
| 33 | 24.200237 | 0.00040105 | 0.00063952 |

三个细网格线性系统的最大绝对残差约为 \(10^{-15}\) 至 \(10^{-14}\) 量级。求解残差小表示离散方程求解充分，**不等于连续问题的离散误差为零**。当前只有一组粗细网格比较，尚不是完整的网格收敛研究。

### 4.5 训练、验证和测试的信息边界

下表为每个场、每次重复的数量。

| 数据类别 | 数量 | 用途 |
| --- | ---: | --- |
| 渗透率训练观测 | 48 | 计算 \(\log k\) 监督误差 |
| 渗透率验证观测 | 24 | 每轮选模、MC 候选掩码接受 |
| 渗透率测试位置 | 504 | 训练结束后的场值误差 |
| 压力训练观测 | 0 | 不使用 |
| 压力验证观测 | 0 | 不使用 |
| 压力参考评价位置 | 576 | 评价辅助压力网络 |
| 域内训练配置点 | 128 | 计算 Darcy 强形式残差 |
| 域内独立评价配置点 | 128 | 评价方程残差 |
| 上下边界训练点 | 每侧32，共64 | 计算无流边界损失 |

渗透率的三类位置互斥。配置点只提供坐标，不提供真实渗透率或真实压力。它们在一次训练中保持固定，不因 RBA 而重新采样。

重复种子为101、202、303，用于生成观测划分、配置点和相应模型初始化。同一场同一次重复的八种方法使用相同观测与配置点；不同重复同时改变观测和初始化，尚未单独分离两类随机性的影响。

实现支持训练统计量定标的对数域观测噪声；本文三场主对照和六场补充实验均采用无噪声配置，评价对象为该观测条件下的恢复。

## 5. 为什么是两个子网络

### 5.1 一个模型表示两个未知函数

当前模型名为 `DarcyPINN`，内部包含渗透率子网络和压力子网络：

\[
\hat k(x,y)=\exp(\hat\ell_\theta(x,y)),\qquad
\hat p(x,y)=p_\phi(x,y).
\]

Darcy 通量及守恒条件为：

\[
\hat{\boldsymbol q}=-\hat k\nabla\hat p,\qquad
r=\nabla\cdot\hat{\boldsymbol q}=0.
\]

因此，仅有 \(\hat k\) 还不能按当前实现计算完整物理残差，还需要一个压力函数及其空间导数。项目选择用第二个经典 MLP 表示这个辅助未知场。

这两个子网络属于一个联合训练模型，不是两份监督数据，也不是两个依次独立训练的预测器。它们通过同一组 Darcy 残差共同更新参数。

理论上也可以采用每次迭代调用可微求解器等其他设计，但当前代码没有采用这些方案。

### 5.2 总体网络文字架构

```text
空间坐标 (x,y)
    |
    +--> 渗透率子网络
    |        坐标归一化
    |        -> 经典编码器
    |        -> 有界角度映射
    |        -> 经典特征块 / 参数化量子线路（二选一）
    |        -> 特征掩码
    |        -> 经典读出层
    |        -> log_k_hat -> exp -> k_hat
    |
    +--> 压力子网络（所有组均为经典 MLP）
             坐标归一化
             -> MLP
             -> 左右压力边界的硬约束变换
             -> p_hat

k_hat + p_hat
    |
    +--> 自动微分 --> q_hat = -k_hat * grad(p_hat)
                         |
                         +--> div(q_hat) --> Darcy 方程损失
                         +--> 上下边界 q_y --> 无流边界损失

log_k_hat + 训练观测 --> 渗透率监督损失
三项损失加权求和 --> 反向传播 --> 联合更新两个子网络
```

### 5.3 仅渗透率监督的能力边界

当前压力边界为：

\[
p(0,y)=1,\quad p(1,y)=0,\quad
q_y(x,0)=q_y(x,1)=0.
\]

没有内部压力观测时，多种正渗透率场可以分别对应满足这些边界的不同压力解。因而，“存在一个满足 Darcy 方程的压力场”本身不能唯一确定渗透率。

当前方案主要依靠稀疏渗透率观测约束场值，再结合网络结构、优化过程和物理一致性进行重建。项目还没有加入去掉物理损失的纯数据消融，因此不能声称已经证明“物理约束一定优于纯数据拟合”。

## 6. 经典 PINN 和量子 PINN 如何构建

### 6.1 共用的渗透率外部结构

两类模型采用相同的编码器和读出层结构：

```text
输入：2维坐标 (x,y)
    |
    v
2*(x,y)-1
    |
    v
Linear(2,24) -> Tanh -> Linear(24,4)
    |
    v
角度 a = pi * tanh(编码结果)，得到4维输入
    |
    v
可替换特征块：4维 -> 4维
    |
    v
逐元素乘以4维二值特征掩码
    |
    v
Linear(4,24) -> Tanh -> Linear(24,1)
    |
    v
标量 log_k_hat
    |
    v
k_hat = exp(log_k_hat)
```

输出直接表示自然对数渗透率，通过指数变换保证 \(k>0\)。没有在预测后用全部真值校准，也没有使用 IDW 残差插值或把已知位置回填来修正主要结果。

### 6.2 经典特征块

```text
4维角度输入
    -> Linear(4,4) -> Tanh
    -> Linear(4,4) -> Tanh
    -> 4维经典特征
```

这是一套完全由经典全连接层构成的坐标网络。在本项目中，它之所以是 PINN 基线，是因为训练确实包含自动微分得到的 Darcy 残差与边界约束，而不是因为类名中带有 PINN。

当前基线不是 Fourier 特征网络，也不是 Fourier 神经算子。

### 6.3 量子特征块

量子组只替换上述4维特征块：

```text
4个量子比特初始化为 |0000>
    |
    v
RY(a0)、RY(a1)、RY(a2)、RY(a3)：分别编码4个输入角度
    |
    v
第1层：
    每个量子比特施加一个具有3个可训练角度的 Rot 门
    CNOT 连接顺序：0->1，1->2，2->3，3->0
    |
    v
第2层：
    每个量子比特施加一个具有3个可训练角度的 Rot 门
    CNOT 连接顺序：0->1，1->2，2->3，3->0
    |
    v
输出 <Z0>、<Z1>、<Z2>、<Z3>，构成4维量子特征
```

输入只在开始通过 RY 编码一次，不是每一层都重新上传输入。

可训练量子门参数为：

\[
2\text{层}\times4\text{比特}\times3\text{角度}=24.
\]

这是真正按量子门和测量期望值定义的参数化线路，但执行方式是经典计算机上的精确状态向量模拟：

| 项目 | 实际设置 |
| --- | --- |
| 框架 | PennyLane |
| 后端 | `default.qubit` |
| 测量 | `shots=None`，精确期望值 |
| 接口 | Torch |
| 求导 | `backprop` |
| 数值类型 | 双精度 |
| 设备 | CPU |

因此可以称为“量子线路模拟下的混合 PINN”，不能称为“已在量子硬件上运行”。量子门参数会通过监督损失和物理损失参与训练，并非固定的随机量子特征。

### 6.4 压力网络和硬边界

所有组使用相同结构的压力网络：

```text
2维坐标 -> 2*(x,y)-1
    -> Linear(2,24) -> Tanh
    -> Linear(24,24) -> Tanh
    -> Linear(24,1)
    -> 原始标量 N_p
    -> p_hat = 1-x + x*(1-x)*N_p
```

由最后的表达式可知，\(x=0\) 时压力为1，\(x=1\) 时为0。因此左右压力边界无需另加损失项；上下无流边界仍通过通量残差训练，并不是由这个表达式自动满足。

### 6.5 参数量及初始化控制

| 组成部分 | 经典组 | 量子组 |
| --- | ---: | ---: |
| 渗透率编码器 | 172 | 172 |
| 可替换特征块 | 40 | 24 |
| 渗透率读出层 | 145 | 145 |
| 压力网络 | 697 | 697 |
| 总可训练参数 | 1054 | 1038 |

两个模型接口相同，但参数量并不严格相同。

对应初始化使用独立随机流：编码器与读出层使用 `seed+11`，特征块使用 `seed+23`，压力网络使用 `seed+37`，MC 抽样使用 `seed+5009`。这样量子块参数数量不同不会改变外部经典层的初始值。

“相同结构与对应初始化”不表示两个实验在训练中共享同一份参数。每组模型都独立训练，更新后相应权重可以不同。

## 7. 损失函数与训练增强

### 7.1 当前有效损失只有三项

总损失为：

\[
\mathcal L=10\mathcal L_k+\mathcal L_{\mathrm{PDE}}+\mathcal L_b.
\]

渗透率监督项：

\[
\mathcal L_k=
\frac{1}{N_k}\sum_i
\left[\hat\ell(x_i,y_i)-\ell_i^{\mathrm{obs}}\right]^2.
\]

物理残差项：

\[
r_i=\nabla\cdot[-\exp(\hat\ell)\nabla\hat p](x_i,y_i),\qquad
\mathcal L_{\mathrm{PDE}}=
\frac{\sum_iw_i r_i^2}{\sum_iw_i}.
\]

上下无流边界项：

\[
\mathcal L_b=\frac{1}{N_b}\sum_i
\left[\hat q_y(x_i,y_i)\right]^2.
\]

基础模型中 \(w_i=1\)。启用 RBA 后，只调整物理残差的点权重。

当前压力观测项权重为0，压力标签数组为空，因此没有压力数据拟合项。左右压力条件由硬约束表达式满足，也不是第四个损失项。

训练对坐标进行自动微分，其中物理残差涉及渗透率的一阶空间导数和压力的二阶空间导数；继续反向传播时还需要这些导数对网络参数的导数。量子模块处于这条可微计算链中。

### 7.2 RBA 具体改变什么

RBA 是基于物理残差的注意力加权。它是经典训练策略，不是另一个量子算法。

代码对应的更新规则为：

\[
u_i^{(t)}=
\frac{|r_i^{(t)}|}{\max(\max_j|r_j^{(t)}|,10^{-12})},
\]

\[
a_i^{(t)}=0.9a_i^{(t-1)}+0.1u_i^{(t)},\qquad
w_i^{(t)}=1+4a_i^{(t)}.
\]

初始 \(a_i=0\)。前20轮使用单位权重，从第21轮开始启用残差更新；权重在1到5之间。残差用于计算权重时先脱离梯度图，权重不作为可训练参数。

该实现将注意力逐步集中到当前相对难满足方程的位置。使用 \(\sum w_i\) 归一化，避免仅因权重整体增加就把物理项总尺度同步放大。

需要明确：

- 加权对象是 Darcy 残差，不是渗透率观测误差。
- 不重新采样配置点。
- 不改变全局损失权重10、1、1。
- 通过共同物理损失影响渗透率网络、压力网络和量子门参数。
- 这是项目中的有界归一化 RBA 变体，不声称逐式复现某篇文献的全部设置。

### 7.3 MC 阈值筛选怎样执行

这里的 MC 指蒙特卡罗随机子批次评估，不是量子测量 shots，也不是蒙特卡罗求解 Darcy 方程。

默认从第40轮开始，每20轮筛选一次，即第40、60、……、300轮。

```text
当前模型及当前有效特征
    |
    v
进行4次随机子批次试验
    每次从训练观测、配置点、边界点中分别抽取最多32个点
    同次试验中，各候选共用这些点及冻结的 RBA 权重
    |
    v
分别临时屏蔽每一个有效特征
    比较屏蔽前后的总训练损失
    |
    v
计算相对损失增量的均值和保守评分
    |
    v
取均值最小的一部分候选，检查阈值与最低保留数
    |
    v
在完整渗透率验证集上比较新旧掩码
    |
    +--> 验证误差不增加：接受掩码，继续训练
    +--> 否则：保留原掩码，继续训练
```

对特征 \(j\) 的第 \(b\) 次试验，计算：

\[
d_j^{(b)}=
\frac{\mathcal L_{\text{屏蔽}j}^{(b)}-\mathcal L_{\text{当前}}^{(b)}}
{\max(|\mathcal L_{\text{当前}}^{(b)}|,10^{-12})}.
\]

四次试验得到均值 \(\bar d_j\) 和样本标准差 \(s_j\)，再计算：

\[
U_j=\bar d_j+2\frac{s_j}{\sqrt4}.
\]

候选先按 \(\bar d_j\) 从小到大排序，只考虑当前有效特征数的25%，按整数规则至少考虑一个，同时保证至少保留两个特征。候选还需满足 \(U_j\le0.01\)。

最后，完整24点验证集上的渗透率损失不得增加，才接受新掩码。筛选不读取测试标签或参考压力。

这个 `均值+2倍标准误` 是工程启发式评分。只有四次随机试验，且子批次可能重叠，不能称为严格统计置信上界，也不能保证测试误差不会增加。

### 7.4 筛选不是量子线路剪枝

MC 只把部分测量特征乘以0。接受筛选后：

- 不删除量子比特或量子门。
- 不改变线路拓扑。
- 不重置网络参数或 Adam 动量。
- 不减少模型登记的可训练参数量。
- 不保证减少量子线路执行成本。

尤其是读出被屏蔽的量子比特仍可能通过纠缠影响其他读出，不能把“屏蔽一个输出特征”解释为“去掉一个量子比特”。

经典模型采用同样的特征屏蔽规则。筛选本身需要额外前向及物理导数计算，耗时计入训练时间。

## 8. 一次完整训练如何进行

### 8.1 固定训练配置

| 项目 | 设置 |
| --- | --- |
| 优化器 | Adam |
| 学习率 | 0.001 |
| 训练轮数 | 300 |
| 梯度裁剪 | 全局梯度范数上限5 |
| 训练点使用方式 | 每轮使用该次运行的全部训练观测与固定配置点 |
| 学习率调度 | 无 |
| 提前停止 | 无，训练到300轮后恢复最佳模型 |
| 数值精度与线程 | CPU，float64，单线程 |
| 验证频率 | 初始第0轮及每个训练轮结束后 |
| 最佳模型标准 | 最小渗透率验证损失 |

当前验证评分为：

\[
S_{\mathrm{val}}=
10\,\operatorname{MSE}
(\hat\ell_{\mathrm{val}},\ell_{\mathrm{val}}^{\mathrm{obs}}).
\]

它不含压力、测试误差或物理残差。固定系数10不改变验证模型的排序。

### 8.2 训练和选模流程

```text
固定当前场、观测划分和重复种子
    -> 初始化一个独立模型
    -> 计算第0轮验证分数并保存初始状态
    -> 重复300轮：
         计算监督、物理、边界误差
         按配置更新 RBA 权重
         计算总损失并反向传播
         梯度裁剪、Adam 更新
         到指定轮次时执行 MC 筛选
         计算完整验证分数
         如更优，保存参数和特征掩码
    -> 恢复最佳验证状态
    -> 评价504个渗透率测试位置
    -> 评价辅助压力、独立配置点残差和流动响应
    -> 保存结果与完整记录
```

保存与恢复的状态包括特征掩码。因此，“训练中某轮接受过筛选”与“最终选出的模型仍采用该筛选”不是同一件事。

验证集同时用于 MC 接受和逐轮选模。这没有直接使用测试数据，但重复利用同一个小验证集仍有适应性过拟合风险；项目没有用嵌套验证证明这一风险可以忽略。

训练时间包括训练循环、循环内验证和 MC 筛选，不包括模型构造、最初验证及最终测试评价。因此表中的时间不是整个实验从数据生成到归档的端到端耗时。

| 研究问题 | 应看的比较 |
| --- | --- |
| 量子模块本身是否有作用 | Q 对 C |

### 9.3 比较条件与主张范围

已经控制了：同一场、同一观测划分、相同配置点和边界点、对应外部层初始化、同一压力网络结构、同一损失权重、学习率、轮数、精度、线程和选模规则。

特征块参数量为经典40个、量子24个，整体比较控制轮数，不控制相同墙钟时间或计算量。三场300轮主协议与六场1000轮补充协议分别回答各自预算下的平均重建问题；同协方差、同观测密度及无噪声条件构成当前适用范围。

等参数扩展、更强周期表示、纯数据网络和等成本对照分别用于后续容量归因、表示选择、物理项贡献及资源效率研究。当前主张定位于既有模块替换的联合训练收益，完整记录场间差异，不将其扩大为所有架构或充分收敛后的排序。

## 10. 指标分别衡量什么

### 10.1 渗透率主指标

主要指标是在504个未参与训练和验证的位置上计算：

\[
E_k=
\frac{\|\hat k_{\mathrm{test}}-k_{\mathrm{test}}\|_2}
{\|k_{\mathrm{test}}\|_2}.
\]

它衡量渗透率本身的相对范数误差，越小越好。训练拟合的是 \(\log k\)，不代表评价也只在对数空间进行。

另一个指标为：

\[
\operatorname{RMSE}_{\log k}
=\sqrt{\operatorname{mean}
[(\hat\ell_{\mathrm{test}}-\ell_{\mathrm{test}})^2]}.
\]

相对 \(L_2\) 误差0.306759不是“准确率69.3241%”，不能用 \(1-E_k\) 解释为分类式准确率。

### 10.2 压力和物理指标

| 指标 | 实际计算内容 |
| --- | --- |
| `pressure_rmse` | 辅助压力网络预测与细网格求解后抽取的参考压力之差，评价576点 |
| `pde_residual_rmse` | 128个独立配置点上的未加权 Darcy 残差 RMSE |
| `neumann_flux_rmse` | 独立上下边界评价点上的法向通量 RMSE |
| `network_flux_imbalance` | 由网络自身输出及导数计算的入口、出口通量不平衡 |
| `downstream_pressure_rmse` | 将预测渗透率送入 FVM 后的压力，与真实渗透率送入相同粗网格 FVM 后的压力之差 |
| `downstream_flux_relative_error` | 上述两次粗网格 FVM 计算的入口总通量相对误差 |

网络压力评价与下游 FVM 评价不是同一件事：前者直接检验压力子网络，后者检验“预测渗透率交给独立求解器后是否产生正确流动响应”。

下游 FVM 使用相同粗网格比较预测场与真实场，避免把粗细网格差异全部算到网络头上。FVM 自身满足离散守恒，也不代表 PINN 网络输出已经同样守恒。

### 10.3 汇总方式

每个方法有9次拟合，下表的“均值 ± 标准差”是这9次运行的均值和样本标准差，不是置信区间。

九次运行只涉及三个独立场，同场重复共享场结构；不同场也复用同一组重复种子。不能把9次拟合或每场504个测试点当成大量独立数据集进行夸大的显著性推断。

### 11.3 量子模块与增强策略的收益分开看

下表的相对降低率定义为：

\[
\frac{\overline E_{\mathrm{基准}}-\overline E_{\mathrm{候选}}}
{\overline E_{\mathrm{基准}}}\times100\%.

| 比较 | 主指标均值差，候选减基准 | 相对降低率 | 9次配对中改善 / 相同 / 变差 |
| --- | ---: | ---: | --- |
| Q 对 C | -0.03033499 | 8.99896% | 7 / 0 / 2 |
| Q+RBA 对 Q | -0.00082386 | 0.26857% | 3 / 0 / 6 |
| Q+MC 对 Q | +0.00000733 | -0.00239% | 0 / 8 / 1 |
| Q+RBA+MC 对 Q | -0.00087731 | 0.28599% | 3 / 0 / 6 |

可以据此作出四点判断：

1. 9.00%的平均重建改善来自基础Q对C，确定表示替换的核心地位。

3. Q+MC的8次相同、1次增加，将筛选定位为适用性对照，而非重建收益来源。
4. 组合模型对Q降低0.29%，对Q+RBA降低0.01747%，作为模块归属证据完整报告。

上述配对计数是观察结果，不是统计显著性检验；少量大改善可以与多数小幅变差同时出现。

## 12. 贡献与使用条件

### 12.1 表示与物理目标的分工

量子特征通过固定接口进入渗透率表示，其平均重建收益分别由三场主对照与六场补充实验支撑。RBA通过残差权重调节方程目标，MC通过完整交叉对照帮助排除错误的收益归属。完整场值、残差和通量结果支持按任务终点选择配置。

### 12.2 适用范围与下一项判别实验

当前证据针对同协方差、无噪声、单一边界工况和逐场拟合，量子线路采用CPU精确模拟。更强周期基线和无纠缠对照用于识别表示来源，等成本比较用于评价资源效率，纯数据消融用于识别Darcy项贡献；统计结构变化、噪声和现场数据则分别检验适用范围。上述问题与已经观察到的平均重建改善分开处理，不以未执行实验推导既有优势。

## 14. 核心结论

V3以辅助压力耦合Darcy约束，在无域内压力标签的条件下恢复稀疏观测场。固定接口的量子特征替换，在三场主对照中使平均留出误差降低9.00%，在六个新场的另一1000轮协议中观察到15.23%的降低；RBA使主实验量子模型独立点残差降低24.07%。量子特征改善给定轮数内的平均重建、残差加权调节物理目标，是现有配对证据共同支持的核心结论。
