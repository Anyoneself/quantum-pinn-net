# 从当前项目到正式投稿的无 Skill 工作流

本流程直接使用项目源码、实验归档、证据台账和可复算脚本，不依赖任何自定义 Skill。目标不是把开发日志改写成论文，而是让每项主张都经过“预先定义—实验归档—独立复算—正文引用—投稿门禁”的闭环。

## 一、当前交付物

| 交付物 | 路径 | 作用 |
|---|---|---|
| 四章主稿 | `paper/PHASE_PERIODIC_PINN_MANUSCRIPT_V2.md` | 学术正文、公式、表图、参考文献 |
| 主张—证据台账 | `paper/CLAIM_EVIDENCE_LEDGER.md` | 限定哪些结论可写、哪些结论被阻断 |
| 探索性实验归档 | `experiments/rba_qpinn_submission_v1/` | 配置、掩码、预测、训练历史与聚合统计 |

## 二、成熟论文流水线

### 1. 冻结探索性证据

- 保留现有实验目录，不覆盖预测数组、掩码、manifest 或训练历史。
- 任何正文数值只允许来自 `aggregate/` 或可由归档数组重新计算的产物。
- 新实验写入新目录，并保存运行配置、软件环境、随机状态、模型状态、原始预测和选择规则。

### 2. 修复确认性实验协议

正式主实验必须同时满足以下条件：

1. 场均值先验只能由观测位置或外部训练数据标定，不得读取空间留出标签的任何统计量。
2. 后处理只能使用观测范围或预先固定的物理范围，不得以完整真实场极值裁剪。
3. 增加留出标签不变性测试：任意改变留出标签，不应改变训练状态、模型选择或后处理输出。
4. 明确区分场内补全与未知场泛化；若研究未知场，必须取消直接场 ID 嵌入并采用稀疏观测编码器。
5. 数据归档必须补齐生成器版本、地质统计参数、许可证、校验和与公开获取方式。

### 3. 预先定义比较设计

主比较采用共享主干、匹配参数量和计算预算的因子设计，至少包含：

- 固定 Fourier 与可学习相位投影；
- 相位混合、正弦激活和门控的单因素配置；
- 动态权重、RBA-only、MC-only 及必要交互项；
- IDW-only、Kriging 或 RBF、SIREN 等场内空间补全基线；
- 若研究未知场，再加入 DeepONet、FNO 或 U-FNO 等同信息条件的算子基线。

在运行前冻结主假设、主指标、重复次数、停止规则、超参数选择边界、代表图选择规则和多重比较处理方法。

### 4. 运行与归档

每次实验至少保存：

- 完整配置与环境版本；
- 数据清单、许可证、掩码或按场划分索引；
- 原始网络输出和任何后处理输出；
- 最佳检查点、模型选择准则及对应指标；
- 各目标损失、目标梯度范数与夹角；
- 墙钟时间、硬件型号、线程数和计时范围；
- 失败运行及排除规则。

### 5. 独立复算

先建立隔离且版本固定的复现环境：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

随后由原始场、空间掩码和预测数组重新计算主指标，并把派生产物写入单独目录：

```bash
.venv/bin/python gen-figures/analyze_manuscript_evidence.py \
  --output reproduction-check/manuscript_supporting_statistics.json

.venv/bin/python gen-figures/generate_manuscript_spatial_figure.py \
  --output reproduction-check/raw_spatial_comparison.png
```

统计脚本同时检查五次运行是否共享同一固定数据、三类空间掩码是否二值且互斥完备、数组是否有限、逐场覆盖是否完整，以及重算值与派生 JSON/CSV 是否一致。确认性归档应延续这种“不修改原始实验归档、由数组重算、派生文件另存”的方式，而不是复制训练日志中的摘要数值。

### 6. 写作与引用门禁

- 第一章仅放研究背景、国内外现状和任务差异。
- 第二章以本文方法和可验证推导为主体；表示性质不得写成性能定理。
- 第三章只报告已完成实验，严格区分留出点指标、完整场指标和诊断性后处理。
- 第四章总结证据支持的结论，并把信息泄漏、对照混杂、数据范围和物理有效性写入局限性。
- 参考文献按首次出现排序；作者、题名、卷期、页码或文章号及 DOI 逐条核验。
- 摘要与结论中的每个定量主张必须能在证据台账中定位。

正文静态门禁可直接执行：

```bash
.venv/bin/python gen-figures/validate_manuscript.py
```

该检查覆盖四章结构、公式/表/图编号、引文首次出现顺序、参考文献完备性、本地图件路径、旧模型名与禁用过程化措辞；作者、单位、公开链接和全体作者确认等不可自动生成的信息以警告形式保留。

### 7. 渲染与投稿包

选定目标期刊后再完成模板适配，并生成：

- 匿名主稿及非匿名主稿；
- 单独高分辨率图件和可编辑矢量源；
- 补充材料与复现实验说明；
- 数据和代码可用性声明；
- CRediT 作者贡献、基金、利益冲突和伦理声明；
- cover letter、亮点及推荐审稿人材料（按期刊要求）。

最终版本需要进行公式编号、图表交叉引用、参考文献、分页、字体嵌入和匿名信息的渲染检查。
